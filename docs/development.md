# Development and verification

Follow [repository instructions](../AGENTS.md) and the [current specification](specification.md). BDD requires failing behavioral tests before each implementation stage, followed by green tests and refactoring. It does not require committed transcripts. Save generated evidence under ignored artifacts and update this note in place.

The implementation was developed tests-first. The latest model behavior passed 99 default tests and one fresh real CPU integration (371.67 seconds), followed by a source/group/fold isolation audit. The verified bank contains 149 × 512 development passage vectors; all 169 original source files were unchanged. Development uses 53 positives and 80 negatives; the final holdout contains 16 positives and 20 negatives, including three of six blogs. Nested model selection/calibration excludes outer test groups; all final holdout identities are excluded from development fitting, references, features, normalization, and model choice.

At the fixed cutoff 50, the last verified holdout accepted 15/16 positives and 8/20 negatives: accuracy 75%, AUROC 0.900, and false acceptance 40%. No settings were adjusted using these results. Small source subsets, earlier project exposure, topic/genre differences, and unavailable email thread provenance limit generalization claims. Detailed generated results remain local; [evaluation](evaluation.md) defines interpretation.

A privacy pass checked all Git-included text against raw/clean private sources using shorter phrase windows and address/phone/URL comparisons. No private-specific disclosure was found; common phrasing/public technical references are not evidence of copied email content. Tests use invented signatures and prose. Private source text and exact identities remain only in ignored inputs/artifacts. Literal scans cannot certify every paraphrase or shorter disclosure.

Documentation was consolidated to the explicit maintained inventory; 73 red/green transcripts were deleted, generated snapshots moved into ignored artifacts, public attribution/licensing preserved, and historical specifications clearly demoted. Four new documentation-policy tests were observed failing before implementation. The checker rejects unexpected docs/generated transcript names and broken local file/heading links. Cleanup verification: 105 default tests passed (one real-inference integration deselected); all four new documentation-policy tests pass, and maintained inventory/local file and heading links pass the standalone checker. The model behavior was unchanged, so expensive real training was not repeated. Generated run output is retained only under ignored artifacts.
