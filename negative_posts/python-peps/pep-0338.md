This PEP defines semantics for executing any Python module as a
script, either with the command line switch, or by invoking
it via .

The switch implemented in Python 2.4 is quite limited. This
PEP proposes making use of the :pep: import hooks to allow any
module which provides access to its code object to be executed.

Python 2.4 adds the command line switch to allow modules to be
located using the Python module namespace for execution as scripts.
The motivating examples were standard library modules such as
and , and the Python 2.4 implementation is fine for this
limited purpose.
